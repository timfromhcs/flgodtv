    Grease Pencil: Basic Draw Mode edit operators
    
    This adds support for some of the basic edit mode operators
    in Draw Mode:
    - Circle, Box, and Pick selection tools.
    - Copy and Paste operators.
    - Delete operator.
    - Transform operators.
    - Draw mode `Stroke` menu.
    
    Pull Request: https://projects.blender.org/blender/blender/pulls/162890
    
    Note: The `x` and `b` keybind for delete and box select has not be added
    because `x` is already used for swapping the brush colors and `b` is
    used for box delete.
    
    Co-authored-by: Falk David <falk@blender.org>
